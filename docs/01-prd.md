# 01 產品需求文件（PRD）— 賭場遊戲練習場

## 1. 一句話
讓完全看不懂賭場的新手，去雲頂（Resorts World Genting）之前，用虛擬籌碼在手機上練到：**看得懂桌面、會下注、看得懂結果**。

## 2. 使用者
- **主要**：第一次去賭場的成年人，繁體中文使用者，對賭場術語與桌面標示（英文）陌生。
- **情境**：手機、可能無網路（車上/山上），單手操作，隨時中斷、隨時續玩。
- **不是**：想練高階策略的老手、想算牌的人。

## 3. 目標與成功指標
| 目標 | 指標 |
|------|------|
| 看懂桌面 | 每款遊戲教學模式完成率 100%（首頁顯示完成度） |
| 會下注 | 練習模式中每一注都有即時合法性回饋（最低/最高/不能碰籌碌時機） |
| 看懂結果 | 練習模式每局結束顯示「牌型 → 結果 → 賠付計算式 → 為什麼」 |
| 現場不慌 | 真實模式：有倒數、荷官口令、只顯示賠付金額，與現場一致 |
| 知道哪些注別押 | 首頁莊家優勢排行榜（低→高），每款遊戲教學含「別押的注」 |

## 4. 範圍（全部實作）
### 4.1 遊戲（17 款）
**桌遊**：百家樂（傳統 5% 佣、免佣 Super 6、老虎百家樂、咪牌模式）、21 點、輪盤（單零）、骰寶、三公、番攤
**撲克桌遊**：Caribbean Stud、Three Card Poker、Casino Hold'em、Ultimate Texas Hold'em、Pai Gow Poker
**老虎機**：3 軸經典（FAFAFA 風）、5 軸 20 線影片機、Hold & Spin（Dragon Link 風）、四級累積獎金機、視訊撲克 Jacks or Better
**撲克室**：德州撲克現金桌（對 3–5 個 AI，No Limit，盲注、抽水）

### 4.2 每款三模式
- **A 教學**：分步驟、每步只講一件事、高亮正在講的區域。內容四大段：桌面配置與英文標示／一局流程（誰發牌、何時下注、何時開牌、何時不能碰籌碼）／輸贏判斷與賠率計算／莊家優勢、哪些注別押、基本策略。
- **B 練習**：真實模擬，玩家下注 → 系統發牌 → 每局結束顯示「牌型 → 結果 → 賠付計算式 → 為什麼」。可隨時開啟提示（建議動作）。
- **C 真實**：完全模仿現場：雲頂大眾區限注、下注倒數、荷官口令（No more bets / Card please）、結果只顯示賠付金額、輸光要手動重置、統計本次總輸贏與局數。

### 4.3 平台
- 單一 `index.html`，內嵌 CSS/JS，離線可開，手機優先。
- 虛擬籌碼開場 RM 1,000，可隨時重置。面額 RM 10/25/50/100/500/1000。
- 進度、餘額、每遊戲輸贏統計存 localStorage。
- 首頁：四區遊戲卡片、教學完成度、籌碼餘額、莊家優勢排行榜。

## 5. 非目標
- 不連網、不真錢、不做帳號。
- 不做多人連線。
- 不做完整撲克 GTO；AI 對手只需「合理、不呆」。
- 不做音效資產（可用 Web Speech API 念口令，屬加分）。

## 6. 規則基準
標準馬來西亞 / 澳門賭場規則：百家樂第三張牌規則表、21 點莊家軟 17 停牌（S17）、輪盤單零。各遊戲細節見 `05-game-rules/`。雲頂房規有差異處在文件中標註「近似，現場以桌上標示為準」。

## 7. 限制與假設
- 純前端、無建置依賴（Node 只用來合併檔案與跑測試）。
- 目標裝置：iOS Safari / Android Chrome 近三年版本，寬 360–430px 為主，桌機亦可用。
- `index.html` 目標 < 1.5 MB。
