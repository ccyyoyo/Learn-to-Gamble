# 03 UI 規格

## 1. 設計系統（`src/core/core.css`）
- CSS 變數於 `:root`：`--felt:#0b5d3b`（綢面綠）、`--felt-dark:#083f29`、`--gold:#d9b451`、`--line:#f3e9c9`（桌面白線）、`--bg:#101418`、`--panel:#1b222a`、`--text:#f2f2f2`、`--muted:#9aa4ad`、`--win:#3ddc84`、`--lose:#ff5c5c`、`--push:#ffd166`、`--accent:#4f9cff`。
- 字體：系統字（`-apple-system, "PingFang TC", "Noto Sans TC", sans-serif`）；數字用 `font-variant-numeric: tabular-nums`。
- 觸控目標 ≥ 44px。下注格最小 56×44px。
- 深色底、綠色桌面。不需要淺色模式。
- 英文術語：`<i class="en">Banker</i>` 顯示為小字、淡色、斜體關閉（`font-style:normal; opacity:.75; font-size:.85em`）。

## 3. 首頁 `#/`
1. 頂部：標題「賭場遊戲練習場」、餘額（大字）、[重置籌碼] 按鈕（confirm）。
2. 四區卡片：桌遊 Table Games／撲克桌遊 Poker Table Games／老虎機 Slots／撲克室 Poker Room。
   卡片：名稱（中/英）、一句摘要、教學完成度環（0–100%）、莊家優勢最佳注、練習統計（局數、淨額）。點卡片 → 選模式（三顆按鈕）。
3. 莊家優勢排行榜：每款遊戲取 `houseEdge` 中 `best` 的一筆，由低到高排序，列出「遊戲 / 注別 / 優勢 %」，並以一句話解釋「數字越低越划算」。老虎機標示 RTP 換算。撲克室顯示「無莊家優勢，抽水 5%（上限 RM 50）」置於最下且標註。
4. 頁尾：規則基準說明、版本、清除所有進度。

## 4. 桌面繪製規範（與現場一致）
- 每個下注格用 `data-bet="<spotId>"`，格內標示 **中文 + 英文** 與賠率（例：「莊 BANKER 1:1」「和 TIE 8:1」）。
- 顏色與位置照該遊戲規格書的 ASCII 圖；用 CSS Grid / 絕對定位；圓弧用 `border-radius`，輪盤用 SVG/`conic-gradient`。
- 牌區：莊/閒各一列；21 點多手橫排；撲克桌遊玩家在下、莊家在上，中間公共牌。
- 荷官位置在上方（螢幕頂端 = 荷官側），玩家在下方，與現場坐向一致。
- 籌碼堆用 `LG.ui.chipStack(amount)`：疊圖 + 金額文字。
- 教學高亮：`.lg-spot--hl` 加金色外框 + 呼吸動畫，其餘區域 `opacity:.35`。

## 5. 籌碼
- 面額顏色：10 藍、25 綠、50 橙、100 黑、500 紫、1000 黃（近似雲頂常見色，教學中標註「現場顏色可能不同，看面額」）。
- 點面額選取 → 點下注格放一枚；長按/右鍵下注格移除一枚；「清除」清空；「重複上注」還原上一局。
- 不足餘額：格子上方 toast「籌碼不足」。超過上限：toast「此注上限 RM x」。低於最低注：發牌時阻擋並說明。

## 6. 練習模式結果面板（四段）
```
牌型 Hand      閒 8（♠7 ♥A）  vs  莊 6（♦K ♣6）
結果 Result    閒贏 PLAYER WINS
賠付 Payout    閒 RM 100 × 1 = +RM 100；莊對 RM 10 → −RM 10；淨 +RM 90
為什麼 Why     閒 8 > 莊 6。莊沒有對子所以莊對輸。
[再來一局]  [看規則]
```
老虎機：顯示中獎線與符號、每線倍數、總贏；未中：顯示「未中獎，本次投入 RM 2.00」。

## 7. 真實模式
- 進入時 modal：「真實模式：限注 RM 50–5,000，倒數 15 秒，不會有解說。」
- 每局：`dealer.say('請下注','Place your bets')` → 倒數 → `('停止下注','No more bets')` → 發牌 → 結果 payoutFlash → 3 秒後自動下一局（可暫停）。
- 餘額低於最低注：覆蓋層「籌碼用完」+ 本次統計（局數、總下注、淨輸贏、最大單局輸/贏）+ [重置籌碌 RM 1,000]。
- 離開真實模式：顯示 session 摘要 modal。

## 8. 無障礍與細節
- 所有按鈕有文字（不只 icon）。
- 牌用文字（A♠）+ 顏色，紅黑對比夠。
- `prefers-reduced-motion` 時關閉轉軸長動畫（直接顯示結果）。
