# Casino Hold'em（id: `casino-holdem`）

## 1. 規則
- 1 副牌。押 **Ante**（可加 **AA Bonus** 旁注）。玩家 2 張、莊 2 張暗、公共牌 3 張翻牌 Flop。
- 玩家看 flop 後：**Fold**（輸 Ante，AA 仍結算）或 **Call = 2 × Ante**。
- 轉牌、河牌翻開。莊 **合格：一對 4 以上**（44+）。
  - 不合格：Ante 依賠付表賠，Call push。
  - 合格且玩家勝：Ante 依表、Call 1:1。合格且莊勝：輸兩注。平手 push。

```
│     你 YOU 兩張                   │

└──────────────────────────────────┘
動作列：棄牌 Fold | 跟注 Call
```

## 4. 策略（提示用，簡化）
Call 除非：無對、無同花/順聽牌、且兩張手牌都比公共牌低（約 18% 手牌棄）。

## 5. 教學大綱（≥ 12 步）
layout、flow（Ante → flop → 決策 → turn/river → 合格）、payout（三情境；AA 用前 5 張）、strategy（幾乎都跟；AA 旁注貴）。

## 6. 真實模式
Ante RM 25–500；AA RM 10–100；決策 30 秒。

## 7. 驗收測試
- 合格：44 合格，33 不合格，A 高不合格。
- 結算三情境；AA 用 5 張判。
- Monte Carlo（上述策略）優勢 1.5%–3%。
