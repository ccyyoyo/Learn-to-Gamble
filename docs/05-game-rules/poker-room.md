# 德州撲克現金桌 Texas Hold'em Cash Game（id: `poker-room`）

## 1. 規則
- No Limit Hold'em，6 人桌（你 + 3–5 個 AI，可選人數）。盲注 **RM 5 / RM 10**。買入 RM 400–1,000（從籌碼餘額轉入；離桌時轉回）。
- **抽水 Rake：每手底池 5%，上限 RM 50，No flop no drop**（翻牌前結束不抽）。
- 標準流程：按鈕 Button 順移；小盲/大盲；翻牌前從大盲左側開始行動；翻牌/轉牌/河牌從按鈕左側第一個未棄牌者開始。
- 行動：Fold / Check / Call / Bet / Raise（最小加注 = 前次加注額）/ All-in。邊池 Side pot 正確計算。
- 攤牌：最佳 5 張（`LG.poker.best`）；平分底池；奇數籌碼給按鈕左側第一位。
- 玩家籌碼 0 → 可再買入（從餘額），或離桌。

## 2. AI 對手（3 種性格，隨機分配）
| 性格 | 翻牌前範圍 | 翻牌後 |
|------|------|------|
| 緊兇 TAG | 前 20% 手牌開池，加注 3× | 有牌下注 60% 底池，聽牌半池，弱牌棄 |
| 鬆兇 LAG | 前 40%，常 3-bet | 常詐唱（25%），大注 |
| 跟注站 Station | 前 50%，很少加注 | 幾乎不棄牌直到河牌 |
決策用 `LG.poker.equity(hole, board, nOpp, 300)` + 底池賠率 + 性格偏移；加入 10% 隨機性。反應時間 0.6–1.8 秒（真實模式）。

## 4. 教學大綱（≥ 16 步）
layout：座位、按鈕、盲注、底池、公共牌、籌碼堆；flow：一手完整流程（誰先動、四條街、攤牌）、最小加注規則、All-in 與邊池、抽水如何被拿走、賭場禮儀（不可 string bet、口頭宣告優先、牌不離桌）；payout：底池分配與抽水計算實例；strategy：起手牌範圓（表格）、位置、底池賠率、別玩太多手、買入與停損。

## 5. 練習模式提示
顯示勝率（Monte Carlo）、底池賠率、建議動作與一句理由；AI 攤牌後顯示其手牌與性格標籤。

## 6. 真實模式
行動 30 秒倒數（超時 = 棄牌/過牌）；無提示；只顯示底池與結果金額；離桌時顯示本次 session 盈虧與手數。

## 7. 驗收測試
- 底池/邊池：三人不同 all-in 金額分配正確；奇數籌碼歸位。
- 抽水：底池 RM 200 → 抽 RM 10；RM 2,000 → 抽 RM 50（上限）；翻牌前結束不抽。
- 行動順序與最小加注規則；按鈕輪轉；盲注扣除。
- 100 手自動對戰（AI vs AI）無錯誤、籌碼守恆（總籌碼 + 累計抽水 = 初始）。
- e2e：玩一手到攤牌。
