# 3 軸經典機（FAFAFA 風）（id: `slot-classic`）

## 1. 概念
單一賠付線、3 軸、每軸 3 格顯示但只有中間線算。符號只有「發」一種字，分三色 + 空白，模仿 Aristocrat FAFAFA：越少符號越容易看懂「怎麼贏」。

## 2. 符號與賠付（乘「每注 credit 數 × credit 價值」；本機為單線，總注 = 每次押注額）
| 中線組合 | 倍數 |
|------|------|
| 金發 金發 金發 | 1000× |
| 紅發 紅發 紅發 | 200× |
| 藍發 藍發 藍發 | 50× |
| 任意三個發（混色） | 10× |
| 任意兩個發 | 2× |
| 任意一個發 | 1× |
| 沒有發 | 0 |

## 3. 轉軸帶（strips，每軸 ≥ 32 停點，由實作調整使 RTP = 90% ± 0.5%）
建議起點：每軸 32 停：金 1、紅 2、藍 4、空白 25（三軸略異，以模擬調整）。`LG.slots.simulateRTP` 需 ≥ 500,000 轉。

## 4. 下注
- credit 價值：RM 0.10 / 0.20 / 0.50 / 1 / 2 / 5；每轉 1–5 credits（max bet 按鈕）。
- 真實模式最低 RM 0.10，最高 RM 25/轉。

## 5. 畫面
```
┌────────────────────────────┐
│  FA FA FA   [PAY TABLE 賠付表] │
│ ┌────┬────┬────┐           │
│ │ 發 │    │ 發 │  <- 上格   │
│ │ 發 │ 發 │    │  <- 中線（金線標示 ←→）│
│ │    │ 發 │ 發 │            │
│ └────┴────┴────┘           │
│  CREDIT RM 1,000.00   BET RM 0.50   WIN RM 5.00 │
│ [面額 ▼] [注數 1-5] [MAX BET] [ SPIN 轉 ] │
└────────────────────────────┘
```
轉軸動畫：每軸滾動 0.8/1.0/1.2 秒後彈停；中獎線閃爍；贏分「滾動累加」。

## 6. 教學大綱（≥ 10 步）
layout：credit / bet / win 表、面額鍵、MAX BET、賠付表按鈕、中線。flow：投注 → 轉 → 停 → 派彩自動加進 credit → 兌現 Cash out（TITO 票券）。payout：一注 RM 0.50 中 10× = RM 5。strategy：RTP 90% 意思是每 RM 100 長期回 90；押注越大不會改變比例；設停損；老虎機沒有「快出了」。

## 7. 練習模式
局末 resultPanel：中線符號、命中組合、倍數、計算式。

## 8. 真實模式
無倒數；只顯示 WIN 金額；餘額 < 最低注 → 破產覆蓋層。

## 9. 驗收測試
- evalLine 7 組合各一測資。
- simulateRTP 500k 轉 RTP 在 89.5–90.5%（測試用 seed）。
- e2e：SPIN 後 3 軸停止，餘額扣除正確。
