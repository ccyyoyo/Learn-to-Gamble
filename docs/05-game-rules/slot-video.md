# 5 軸 20 線影片機（id: `slot-video`）

## 1. 概念
5×3、20 條固定線、Wild、Scatter 觸發免費轉。主題「財神/龍」。RTP 目標 94% ± 0.5%。

倍數乘 **每線注**。線由左至右，一線只取最高賠付。

## 4. 下注
每線 RM 0.10 / 0.20 / 0.50 / 1 / 2 / 5；線數固定 20（可選 1/5/10/20 教學用）。總注 = 線 × 每線。

## 5. 畫面
5×3 網格 + 左右線號碼標籤（點線號亮線路徑）；上方 [PAY TABLE]、免費轉計數；下方 credit/bet/win、[LINES][BET/LINE][MAX BET][SPIN]。免費轉中背景變色，「FREE SPINS 8 LEFT」。

## 6. 教學大綱（≥ 12 步）
layout：線、每線注、總注、Wild/Scatter 圖示解釋、賠付表怎麼讀（倍數 × 每線注！不是總注）。flow：轉→停→線路亮→贏分加總→免費轉觸發流程。payout：一線 3 個財神 = 50 × RM 0.10 = RM 5；同時兩線加總。strategy：RTP、波動、免費轉不是「賺」而是 RTP 的一部分；別追損。

## 7. 驗收測試
- evalLines：wild 替代、左起連續、一線取最高、scatter 不算線。
- simulateRTP 500k 轉（含免費轉期望）RTP 93.5–94.5%。
- e2e：轉一次、觸發（seed）免費轉並自動轉完。
