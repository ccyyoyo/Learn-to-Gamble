# 百家樂 baccarat：變更請求與實作假設

## CR-1 免佣桌（super6 / tiger）的練習提示不能照抄「押莊 1.06%」
- 規格 §7 寫「建議：押莊（優勢最低 1.06%）」。但在 super6 / tiger 桌，莊贏 6 點只賠一半，莊的優勢是 **1.46%**，閒仍是 **1.24%**（00-common.md 的數字），所以閒反而略好。
- 做法：classic / squeeze 照規格顯示「押莊（1.06%）」。super6 / tiger 改成「押閒（1.24%）或莊（1.46%）；莊 6 點只賠一半，所以閒反而略優」。教學的 strategy-bet 步驟也依變體說明。
- 需要：協調者確認。沒有改動任何數字。

## CR-2 旁注的紅字改寫實際優勢，不寫「> 7%」
- 規格 §7 寫旁注顯示「高風險，優勢 > 7%」。但 Big Tiger 是 6.03%、Small Tiger 是 5.36%，都低於 7%。
- 做法：每個旁注格（含和）在提示開啟時顯示「高風險 · 優勢 X%」，X 取自 00-common.md。

## CR-3 houseEdge 只有一個陣列，不能依變體設定
- `houseEdge` 列出所有注別：莊（佣）1.06% `best`、閒 1.24%、莊（免佣）1.46%、和、對子、Super 6，以及五個老虎旁注（標 `approx: true`，因為 00-common 寫「近似」）。
- 首頁卡片與排行榜不管哪個變體，都顯示 1.06%。若要依變體顯示，需要核心支援 `variants[i].houseEdge`（建議，不急）。

## 假設（規格沒寫明的地方）
- **Super 6 旁注的真實模式限額**：比照對子/老虎旁注，用 RM 10–1,000。
- **下注規則**：`Bets` 的整桌 `min` 設 0，每格限額用 `spotRules`（真實模式）或 `perSpotMin/Max`（練習/教學，RM 10–100,000）處理。真實模式允許只押旁注，也允許莊閒兩邊都押（規格沒有禁止）。`ctx.checkBroke()` 仍以 RM 50 為準。
- **咪牌**：這是模擬，所以玩家可以掀莊閒兩邊的牌。前四張一起蓋著發下，四張都掀開後才補第三張；閒的第三張、莊的第三張也要逐張掀（荷官說「閒補牌，請開牌」）。全部掀完才唱牌、結算。真實模式也一樣：沒有自動翻牌，玩家掀完之前這一局會停住。開始掀牌時，牌區會自動捲進畫面。
- **牌靴**：8 副、切牌 14 張。建立時執行 `burnStart`。每局開始前若 `needsShuffle()` 就換新牌靴，荷官說「洗牌 Shuffling」，珠盤路也清空（和現場換靴一樣）。
- **路單**：只做珠盤路（6 行、由上而下再往右、至少 12 欄、可橫捲、紅莊藍閒綠和、左上紅點 = 莊對、右下藍點 = 閒對）。沒有做大路。路單存在 instance 裡，切換模式或變體會重新 `create`，路單就清空。
- **教學示範路單**是固定資料（`DEMO_ROAD`），只在教學 layout-road 步驟、路單還是空的時候填入。
- **發牌後桌上的牌會留著**，直到下一局按發牌（或倒數結束）才清掉，讓玩家看結果面板時還能對照桌面。
