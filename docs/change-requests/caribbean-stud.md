# caribbean-stud — 變更請求與實作假設

沒有需要改核心 API 的項目。以下是規格沒寫明、由我決定的地方，以及給協調者的數字說明。

## CR-1 累積獎金旁注的莊家優勢（規格「>25%」遠低於實際值）
- 規格：旁注固定 RM 5，彩金為固定金額（同花 RM 50／葫蘆 RM 100／四條 RM 500）＋獎池 10%／100%。
- 以 5 張牌型組合數精確計算（`logic.progressiveEdge(pool)`）：獎池 RM 100,000 時優勢 **≈ 86.5%**；獎池約 RM 158 萬才打平。
  規格「獎池低時 >25%」是以 1 元注為準的常見數字；本桌注額 RM 5、彩金沒有乘以注額，所以實際高很多。
- 我的做法：數字不改；教學與提示面板顯示即時計算值（「約 86.5%，遠超過 25%」）。
  `houseEdge` 另加一筆 `{bet:'累積獎金旁注（獎池 RM 10 萬時）', edge: 86.54, approx: true}`（`best` 仍是 Ante 5.22%）。若排行榜/卡片只想要規格表上的數字，協調者可刪掉這一筆。

## CR-2 旁注規則假設
- **棄牌 = 旁注也輸**（多數賭場規則：要留在牌局才領累積獎金）。教學「旁注獨立結算」一步有寫。
- 固定彩金為「淨贏」，本金 RM 5 另外退回（拿回 RM 55 / 105 / 505）。
- 同花順付獎池 10%，獎池扣掉彩金但不低於種子 RM 100,000；皇家同花順付 100% 後獎池回種子。
- 獎池只在練習/真實模式成長（+RM 3.5／注，No more bets 時）與扣減；教學模式不動 `store.jackpots`。

## CR-3 跟注資金
- 下注階段不擋 Ante；若餘額不足以再放 2×Ante，放籌碼時 toast 提醒。
- 決策時若餘額不足 2×Ante，「跟注」按鈕停用並標示「餘額不足以跟注」，只能棄牌（不會卡住流程；`checkBroke` 仍以最低注判斷）。

## 備註
- Monte Carlo（規格簡化策略，100 萬手，seed 20260927）：Ante 優勢 ≈ 5.47%（多個 seed 5.25–5.52%），落在 4.5–6%。最佳策略 5.22% 為規格數字。
- No more bets 後停 500ms 再喊「發牌 Dealing」，否則橫幅會被立即覆蓋、玩家看不到停止下注口令（`_demo` 也有同樣情形，供核心參考）。
- 真實模式決策 30 秒用 `LG.ui.countdown`（與下注倒數共用同一個顯示；兩者不重疊）。
