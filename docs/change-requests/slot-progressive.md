# slot-progressive 變更請求與實作備註

## CR-1 真實模式進場說明寫「倒數 15 秒」（核心 32-modes.js）
- 同 slot-holdspin CR-1：老虎機真實模式不倒數，但進場 modal 文字固定寫倒數秒數。建議 slots 分類改文案或 `countdown: 0` 時隱藏。

## CR-2 規格缺口：獎池是固定 RM，若非最大注照樣全額派彩，低注 RTP 會超過 100%
- 規格：種子 RM 20 / 50 / 500 / 10,000；非最大注時 GRAND 格變 MAJOR；RTP 92%（最大注，非最大注更低）。
- 問題：輪盤觸發率與注額無關（約 1/143 轉）。若總注 RM 2 也全額拿 MINI RM 20…MAJOR RM 500，輪盤期望 ≈ RM 110／觸發 → 光輪盤就貢獻約 38% RTP，總 RTP ≈ 124%，與「非最大注更低」和教學重點「要玩就一定最大注」相反。
- 我的決定：**非最大注的輪盤獎金 = 獎池 × (總注 ÷ RM 100)**（最大注比例 = 1，拿全額），且 GRAND 格變 MAJOR（照規格）。獎金牌顯示獎池全額，下方一行提示「非最大注：沒有 GRAND，獎金只付 x%」。成長仍照規格「每轉 總注 × 0.5/0.5/0.8/1.2%」，不論注額都貢獻 → 正是教學要講的「付出成長貢獻卻無資格」。
- 結果：最大注 RTP **92.19%**；所有非最大注 RTP **86.64%**。

## 實作備註
- 20 線、總注 = 20 × 每線注（RM 0.10–5）；最大注 = RM 100。限注 RM 2–100。
- 基礎賠付表同 slot-video 結構（金龍 WILD 只在第 2–4 軸；鳳凰 50/200/1000、醒獅 25/100/400…），**不含 Scatter 免費轉**（JACKPOT 符號取代 Scatter 的角色）。JACKPOT 不賠線、不被 WILD 替代。
- 每軸 1 個 JACKPOT 停點 → 觸發約 1/143 轉（規格「約 1/150」）；最大注平均約 1,711 轉中一次 GRAND。
- 輪盤：12 格固定排列（GRAND 在第 0 格），落點 `LG.rng.int(0, 11)` 在按下旋轉時決定；modal 旋轉 3 秒（`LG.ms`），停下後「收下 Collect」才入帳並回種子。動畫中離開頁面照樣入帳、回種子。
- RTP 驗證：`logic.exactRTP()` 由轉軸帶精確計算（單元測試 92 ± 0.3%）；`[slow]` `simulateRTP` 20 萬轉（seed 5）線獎實際模擬、輪盤以種子期望值計。
- 老虎機不用 `ctx.bettingWindow` / `ctx.nextRound`（真實模式不倒數）；每轉 debit → credit → recordRound → explain → checkBroke。
